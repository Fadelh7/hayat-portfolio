# Hayat Portfolio

A modern, single-page portfolio website for an artist built with Next.js, TypeScript, and Tailwind CSS.

## Features

- 🎨 Modern, clean design
- 📱 Fully responsive
- ⚡ Fast and optimized performance
- 🖼️ Image gallery with modal view
- 📝 Contact form
- 🎯 Smooth scroll navigation

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Shadcn UI Components
- Lucide Icons

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/hayat-portfolio.git
```

2. Install dependencies:
```bash
npm install
# or
yarn install
# or
pnpm install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `/app` - Next.js app directory containing all pages and layouts
- `/components` - Reusable UI components
- `/public` - Static assets (images, etc.)
- `/styles` - Global styles and Tailwind CSS configuration
